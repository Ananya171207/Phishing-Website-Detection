About the project

Phishing detection with machine learning.

PhishGuard AI is an academic web application that connects a trained {{ model_name }} model to a safe, usable URL-scanning interface.

How it works

The app normalizes a submitted URL, extracts lexical signals, optionally fetches public webpage HTML, adds domain information, arranges all values in the model’s original order, and returns a prediction with probability.

Feature groups

The {{ feature_count }} inputs include URL length and symbols, host and subdomain structure, suspicious terms, redirects, links, forms, media, HTML behaviour, DNS, and WHOIS-derived properties.

Important limitation

Some training features originally depend on changing third-party ranking or search services. This implementation leaves those values neutral when reliable API access is unavailable, so it should be evaluated again on fresh real-world URLs before being treated as a security product.

Safety design

The scanner accepts only HTTP(S) URLs, rejects private or local network destinations, limits response size, uses a timeout, and does not intentionally store scan history.
